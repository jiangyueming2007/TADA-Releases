## 软件功能

- **聊天**：私聊与群聊，发送文字、图片和文件。
- **动态互动**：发布动态、关注与粉丝、点赞和评论。
- **AI 多会话**：管理独立会话，选择 AI 服务与模型。
- **个人资料与账号安全**：资料和头像设置、邮箱验证、修改及找回密码、本机屏幕保护。
- **通知与社团管理**：分类互动通知，以及不同规模群组的成员、组织和活动管理。

## 0.3.1 新增功能

- **禁言时长选择**：群管理支持10分钟、1小时、24小时、7天和30天，仍可随时解除有权限管理的成员禁言。
- **活动参与统计**：显示报名人数（含已签到）、已签到、待签到和签到率，刷新同步更新统计与分页名单；统计基于当前群成员的回应。
- **本机屏幕保护**：从“设置与隐私→账号与安全”开启系统支持的窗口保护，减少截图、录屏及最近任务预览暴露；设置保存在本设备，退出登录后仍保留，并兼顾恢复凭据页面的临时保护。只作用于本机TADA窗口，不限制复制/保存/转发，也不能阻止外部设备拍屏。
