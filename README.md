# TADA

TADA 是一款集世界动态、友人交流、私聊、群组和 AI 对话于一体的 Android 应用。

本仓库提供统一的原始安装包下载入口，减少中间转发异常，方便核对版本与文件完整性。

## 下载

[下载 TADA 0.3.4 测试版](https://github.com/jiangyueming2007/TADA-Releases/releases/tag/v0.3.4)

下载 Release 中的 `TADA-0.3.4.apk`，直接覆盖安装。请保留已有应用及其数据。

## 功能

- 世界与友人动态、关注、评论、转发、点赞与收藏。
- 私聊与群组、图片和文件消息、端到端加密聊天。
- 群头像、高级群组＋的群组动态账号与负责人管理。
- AI 多供应商对话、附件与实时返回。
- 个人主页、主题与外观设置、多账号快捷切换。

## 0.3.4 更新

- AI 正文与模型明确返回的思考过程实时显示，支持停止生成。
- 世界动态与聊天图片全屏查看，支持捏合缩放、双击放大/还原、轻点纯净显示、保存和分享；动态图片提供快捷互动。
- 私聊列表增加在线圆点；新增在线状态双向隐藏设置。
- 「我的」增加添加账号与切换账号。
- 高级群组＋动态账号名称后增加蓝底白勾标识。

模型不提供思考过程时，只实时展示正文。版本仍处于测试阶段。
