## 软件功能

- **聊天**：私聊与群聊，发送文字、图片和文件。
- **动态互动**：发布动态、关注与粉丝、点赞和评论。
- **AI 多会话**：管理独立会话，选择 AI 服务与模型。
- **个人资料与账号安全**：资料和头像设置、邮箱验证、修改及找回密码。
- **通知与社团管理**：分类互动通知，以及不同规模群组的成员、组织和活动管理。

## 0.3.0 新增功能

- 私聊、群聊正文与私密附件的端到端加密。
- 设备批准与撤销、安全码核对及独立恢复凭据。
- 通过邮箱验证码修改密码、找回密码。
- 点赞、新关注、评论的分类通知页面、已读管理与快速切换。
- 基础、高级、高级＋群组：成员管理容量分别为 **300 / 3000 / 10000 人**，提供部门、分级管理员、入群审批、加密公告确认、活动报名与签到、投票和管理记录；高级＋增加多级组织与批量分配。容量指成员管理范围，不代表同等数量手机的并发承诺。
- 后续版本的签名更新入口；当前自动更新网关尚未启用，升级请使用本仓库的安装包。

私密聊天正文与私密附件默认端到端加密；动态（含友人可见动态）、用户主动发给 AI 的内容，以及群角色、部门等必要管理元数据仍按对应功能处理。独立安全审计及完整实机验证仍在待验收范围。
