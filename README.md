# TADA

TADA 是一款集世界动态、友人交流、私聊、群组和 AI 对话于一体的 Android 应用。

本仓库提供统一的原始安装包下载入口，减少中间转发异常，方便核对版本与文件完整性。

## 下载

[下载 TADA 0.3.5 测试版](https://github.com/jiangyueming2007/TADA-Releases/releases/tag/v0.3.5)

下载 Release 中的 `TADA-0.3.5.apk`，直接覆盖安装。请保留已有应用及其数据。

## 功能

- 世界与友人动态、关注、评论、转发、点赞与收藏。
- 私聊与群组、图片和文件消息、端到端加密聊天。
- 群头像、高级群组＋的群组动态账号与负责人管理。
- AI 多供应商对话、附件与实时返回。
- 个人主页、主题与外观设置、多账号快捷切换。

## 0.3.5 更新

- 举报可填写具体理由、附加图片，并查看工单处理结果。
- 通知管理新增举报入口，举报工单不增加通知数字。
- 新增创始人与 P0 行权模块，绑定当前个人账号使用；P0 接收随机分配的举报工单。
- 支持动态警告、删除及由创始人执行的限时处罚。
- 创始人可审核友人动态；管理模块无法读取其他用户的私聊和群聊。

版本仍处于测试阶段。
