# TADA

TADA 是一款集世界动态、友人交流、私聊、群组和 AI 对话于一体的 Android 应用。

本仓库提供统一的原始安装包下载入口，减少中间转发异常，方便核对版本与文件完整性。

## 下载

[下载 TADA 0.3.6 测试版](https://github.com/jiangyueming2007/TADA-Releases/releases/tag/v0.3.6)

下载 Release 中的 `TADA-0.3.6.apk`，直接覆盖安装。请保留已有应用及其数据。

如果旧版在应用内更新时报“解析软件包时出现问题”，请用系统浏览器打开此下载页，下载后从浏览器下载列表或文件管理器确认覆盖安装一次。

## 功能

- 世界与友人动态、关注、评论、转发、点赞与收藏。
- 私聊与群组、图片和文件消息、端到端加密聊天。
- 群头像、高级群组＋的群组动态账号与负责人管理。
- AI 多供应商对话、附件与实时返回。
- 个人主页、主题与外观设置、多账号快捷切换。
- 举报理由与图片工单、创始人及 P0 行权管理。
