## 软件功能

- **聊天**：私聊与群聊，发送文字、图片和文件。私密聊天正文与私密附件默认端到端加密。
- **动态互动**：发布动态、关注与粉丝、点赞和评论。
- **AI 多会话**：管理独立会话，选择 AI 服务与模型。
- **个人资料与账号安全**：资料与头像设置、邮箱验证、修改及找回密码、账号修改和本机屏幕保护。
- **通知与社团管理**：分类互动通知，以及群组成员、组织和活动管理。

## 0.3.2 新增功能

- **更清晰的正式界面**：移除“本地”标识和过时开发提示。
- **关注私信**：关注时可附一条加密文字留言，在“世界与友人→通知管理→私信”查看。互相关注后可通过普通聊天继续交流。
- **修改 TADA 账号**：点击我的页面昵称下方账号，或进入“账号与安全”。支持3–32位数字、英文字母和下划线，不区分大小写；修改后一年内不可再次修改。原聊天与关注关系保留。
- **保护搜索隐私**：添加友人使用完整 TADA 账号精确搜索；昵称可重名，邮箱不参与该搜索。
- **检查更新**：从“我的→检查更新”获取签名验证的新安装包，安装仍需本人确认。

动态（含友人可见动态）、主动发给 AI 的内容、公开资料和必要群管理信息按各自功能处理。当前仍为测试候选版，独立安全审计及完整实机验证尚未完成。
