## 软件功能

- **聊天**：私聊与群聊，发送文字、图片和文件。私密聊天正文与私密附件默认端到端加密。
- **动态互动**：发布动态、关注与粉丝、点赞和评论，关注时可附一条加密私信。
- **AI 多会话**：管理独立会话，选择 AI 服务与模型。
- **个人资料与账号安全**：头像设置、邮箱验证、修改及找回密码、TADA 账号修改和本机屏幕保护。
- **通知与社团管理**：分类互动通知，以及群组成员、组织和活动管理。

## 0.3.3 新增功能

- **好友在线状态**：私聊对方名称后的蓝色小圆点表示在线，灰色表示离线。异常断网时状态可能有短暂延迟。
- **群头像**：群主和管理员可设置群头像，群聊列表与群资料同步展示。
- **群组对外账号**：每个高级群组＋自动拥有对外动态账号。群主可指定或收回动态负责人；负责人发布时可选择本人或群组账号，群组动态公开展示。
- **主页账号一致**：公开主页中的 TADA 账号与“我的”保持一致。

动态（含友人可见动态）、主动发给 AI 的内容、公开资料和必要群管理信息按各自功能处理。当前仍为测试候选版，独立安全审计及完整实机验证尚未完成。
